🎓 Videochamada com Tradução para Libras — Protótipo de TCC

Projeto acadêmico desenvolvido como Trabalho de Conclusão de Curso (TCC) na Universidade Cruzeiro do Sul. A plataforma de videochamada inclusiva integra tradução em tempo real para a Língua Brasileira de Sinais (Libras), utilizando WebRTC para comunicação em tempo real e uma API de reconhecimento de voz para transcrever a fala e exibir a interpretação correspondente em Libras, promovendo acessibilidade na comunicação para pessoas com deficiência auditiva.

Tecnologias: Python,FastAPI, WebRTC, JavaScript, React, Node.js e APIs de reconhecimento de voz

💼 Simulador Financeiro Interativo — Projeto Empresarial

Aplicação web para simulação de investimentos e planejamento financeiro, desenvolvida para uma empresa. Com React no frontend e Python com Flask no backend, o sistema permite simular diferentes cenários de investimento, calculando investimento inicial, margem, depreciação, custos operacionais, Valor Presente Líquido (VPL), payback e amortização. Os resultados são apresentados por meio de gráficos interativos, com histórico de simulações e comparação de cenários para suporte à tomada de decisão. O sistema permite exportação dos dados nos formatos XLSX e CSV. Os cálculos financeiros são processados com as bibliotecas Pandas e NumPy.

Tecnologias: React, Python, Flask, Pandas e NumPy
